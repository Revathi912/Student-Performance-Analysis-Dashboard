# 🎓 Student Performance Analysis Dashboard | Power BI

## 📌 Project Overview

The Student Performance Analysis Dashboard is an interactive Power BI project designed to analyze student data, academic performance, department-wise distribution, placements, and scholarship details.

This dashboard provides meaningful insights through interactive visualizations and KPIs, helping users understand student performance and institutional statistics.

## 📊 Dashboard Preview

![Student Performance Analysis Dashboard](dashboard.png)

## 🎯 Project Objectives

* Analyze the overall student population.
* Monitor average CGPA.
* Evaluate department-wise student distribution.
* Track student placement statistics.
* Analyze scholarship distribution.
* Present insights using interactive dashboards.

## 🛠️ Tools & Technologies

* **Power BI Desktop** – Data visualization and dashboard creation
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Microsoft Excel** – Data source

## 📈 Key Performance Indicators (KPIs)

## 📊 Dashboard Visualizations

### Student Performance Analysis

* Placement Status Filter

## 💡 Key Insights

* The dataset contains 1,000 students.
* The average CGPA is 7.80.
* A total of 515 students are placed.
* There are 505 scholarship students.
* MECH has the highest department student count, with 140 students.
* ECE has the lowest department student count, with 114 students.
